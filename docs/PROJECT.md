# Project Strategy: Dirt & Co (WebForge v9.1 Vercel Build)

## 1. Brand Identity
- **Name:** Dirt & Co
- **Tagline:** High-Performance Electric Dirt Bikes & Outback Moto Engineering
- **Domain:** DOMAIN.com (Pending final DNS switch)
- **Primary Keyword:** electric dirt bike
- **HQ:** Sunshine Coast, Queensland, Australia
- **Target Market:** Australian off-road riders, private property owners, motocross enthusiasts, junior riders, station managers seeking silent, high-torque electric performance.

## 2. Competitive Edge & Positioning
- **Terrain Hardening:** 40°C+ ambient thermal dissipation, IP67 sealed electronics for river crossings and bull-dust.
- **Instant Torque:** 0-RPM peak torque delivery (up to 540Nm at the wheel) beating conventional 250cc-450cc 4-stroke gas bikes.
- **Zero Trail Noise:** Unlocks private acreage riding and noise-restricted properties without complaints.
- **Australian Backing:** Sunshine Coast workshop, 2-Year warranty, local parts inventory, PayID and Crypto 5% discount settlement.

## 3. Architecture & Standards
- **Framework:** Next.js App Router (React 19, TypeScript), Tailwind CSS.
- **Deployment:** Vercel via GitHub auto-deploy (`trailingSlash: true`, live API routes).
- **SEO & AI Visibility:** Full GEO/AEO entity optimization, Store/Organization + Product schema, RFC 9727 API catalog, UCP 1.0, MCP Streamable HTTP server card, WebMCP client discovery.
